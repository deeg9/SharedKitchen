# Requirements: SharedKitchen

**Defined:** 2026-03-30
**Core Value:** Households can collaboratively plan, shop for, and cook dinners together in real-time — eliminating the daily "what's for dinner?" friction.

## v4.0 Requirements

Requirements for AI Vision — Scan, Snap & Add. Each maps to roadmap phases.

### Vision Foundation

- [x] **VIS-01**: User can capture a photo from camera within the app via a reusable camera sheet
- [x] **VIS-02**: Captured images are compressed client-side to ~200KB before upload
- [x] **VIS-03**: Camera permission is requested with contextual pre-prompt before first use
- [x] **VIS-04**: Edge Function accepts base64 images and routes to Gemini 2.5 Flash vision by intent (scan/identify)
- [x] **VIS-05**: Vision API calls are rate-limited per intent with free-tier caps tracked in ai_usage_log

### Fridge/Pantry Scan

- [ ] **SCAN-01**: User can photograph fridge or pantry shelves and receive a list of identified items with brand-level detail
- [ ] **SCAN-02**: User can review, edit, add, or remove items on a confirmation screen before saving
- [x] **SCAN-03**: Confirmed items are bulk-added to On Hand inventory with auto-assigned categories
- [x] **SCAN-04**: Duplicate items are detected via normalized name matching and merged or flagged
- [ ] **SCAN-05**: User can scan multiple shelves/areas and merge results into a single review before saving

### Food Photo → Recipe Discovery

- [x] **RCPE-01**: User can photograph food or a screenshot and have the dish identified by AI
- [x] **RCPE-02**: AI shows confidence level and allows user to correct the dish name before searching
- [x] **RCPE-03**: App searches the web and presents 2-3 recipe options for the identified dish
- [x] **RCPE-04**: User can select a recipe and import it into their recipe book via existing import pipeline

### Food Photo → Meal Logging

- [x] **MEAL-01**: After dish identification, user can choose between "Find Recipes" or "Log as Meal"
- [x] **MEAL-02**: User can select a day and meal slot (breakfast/lunch/dinner) to log the identified dish
- [x] **MEAL-03**: Logged meal appears on the weekly meal plan calendar

## Future Requirements

### Vision Enhancements

- **VISE-01**: Barcode scanning for precise product identification
- **VISE-02**: Expiration date detection from packaging
- **VISE-03**: Nutrition label scanning and auto-population
- **VISE-04**: Receipt scanning to auto-log grocery expenses

## Out of Scope

| Feature | Reason |
|---------|--------|
| Barcode scanning | Adds native dependency complexity; brand-level vision is sufficient for v4.0 |
| Receipt/nutrition label scanning | Different vision pipeline; defer to future milestone |
| Saving original photos with pantry items | Storage cost concern; items are text-based |
| AI-generated recipe images | Extract from source URLs instead (existing decision) |
| Real-time collaborative scanning | Single-user scan with shared results via existing Realtime sync |
