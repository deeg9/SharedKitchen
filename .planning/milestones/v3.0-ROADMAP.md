## Decisions Made

- Supadata chosen for transcript extraction (single REST endpoint, all platforms, $17/mo at scale)
- Extend existing parse-recipe-url Edge Function with video branch (same auth, same caching)
- Gemini Flash for transcript parsing with is_recipe confidence check for non-recipe rejection
- Free tier: 3 video imports/month, unlimited premium — uses existing ai_usage_log table
- expo-share-intent for iOS share sheet, accepts all URLs, isVideoUrl() filters client-side
- pantry_items table with RLS, real-time sync, auto-copy from grocery check-offs
