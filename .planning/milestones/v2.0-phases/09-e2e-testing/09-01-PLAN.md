    Create the `.maestro/` directory and the following YAML flow files. Read app.json first to get the correct bundle identifier for the appId config.

    **`.maestro/config.yaml`:**
    ```yaml
    appId: {bundle identifier from app.json, e.g., com.mise.app}
    ```

    **`.maestro/auth-signup.yaml`:**
    ```yaml
    appId: {from app.json}
    ---
    - launchApp:
        clearState: true
    - assertVisible: "Create Account"
    - tapOn:
        id: "sign-up-email-input"
    - inputText: "testuser+${Date.now()}@example.com"
    - tapOn:
        id: "sign-up-password-input"
    - inputText: "***REMOVED***"
    - tapOn:
        id: "sign-up-submit-button"
    - assertVisible:
        text: ".*"
        timeout: 10000
    ```
    Note: Signup will navigate to onboarding or home. Use a generous timeout for network calls. The test email uses Date.now() to be unique per run. If the sign-up screen has a confirm-password field, add that input step too.

    **`.maestro/auth-login.yaml`:**
    ```yaml
    appId: {from app.json}
    ---
    - launchApp:
        clearState: true
    - assertVisible: "Sign In"
    - tapOn:
        id: "sign-in-email-input"
    - inputText: "testuser@example.com"
    - tapOn:
        id: "sign-in-password-input"
    - inputText: "***REMOVED***"
    - tapOn:
        id: "sign-in-submit-button"
    - assertVisible:
        text: ".*Plan.*|.*Recipes.*|.*Welcome.*"
        timeout: 10000
    ```

    **`.maestro/auth-logout.yaml`:**
    ```yaml
    appId: {from app.json}
    ---
    - launchApp
    - tapOn:
        id: "profile-tab"
    - scrollUntilVisible:
        element:
          id: "profile-sign-out-button"
        direction: DOWN
    - tapOn:
        id: "profile-sign-out-button"
    - assertVisible: "Sign In"
    ```
    Note: This flow assumes the user is already logged in (no clearState).

    **`.maestro/onboarding-flow.yaml`:**

    - inputText: "***REMOVED***"
    - tapOn:
        id: "sign-up-submit-button"
    # Step 1: Welcome

        text: ".*Welcome.*|.*Get Started.*"
        timeout: 10000
    - tapOn:
        id: "onboarding-welcome-continue"
    # Step 2: Create Household

        id: "onboarding-household-name-input"
    - inputText: "Test Kitchen"
    - tapOn:
        id: "onboarding-household-continue"
    # Step 3: Invite Members (skip)
    - tapOn:
        id: "onboarding-invite-skip"
    # Step 4: Add Recipes (continue/skip)
