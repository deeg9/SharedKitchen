       - `formatTime(seconds: number): string` -- format as M:SS or H:MM:SS
       - `useCountdown(durationSeconds: number)` hook:
         - State: remaining (number), isRunning (boolean)
         - Refs: startTimeRef, pausedRemainingRef, intervalRef
         - start(): record startTime as Date.now(), store current remaining in pausedRemainingRef, set isRunning true
         - pause(): clear interval, set isRunning false, store remaining
         - reset(): clear interval, set remaining to durationSeconds, set isRunning false
         - useEffect for isRunning: setInterval every 250ms, compute elapsed from wall clock, remaining = pausedRemainingRef - elapsed, clamp to 0, on 0 clear interval + haptic notification
         - useEffect for AppState: on 'active', if isRunning, recalculate remaining from wall clock (same formula)
         - Cleanup: clear interval on unmount
         - Return: { remaining, isRunning, isComplete: remaining === 0, start, pause, reset, formattedTime: formatTime(remaining) }
