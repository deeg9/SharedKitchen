Only schedule if trigger date is in the future. Store notification IDs in AsyncStorage under key `notif_leftover_{leftoverId}` as JSON array. Returns array of scheduled IDs.

For >= 100%: check AsyncStorage key `budget_alert_{year}_{month}_100`, if not sent, fire immediate notification (trigger: null) with title "Budget exceeded!", body "{householdName} has exceeded the monthly budget of ${budgetTarget}.", data { type: 'budget_warning', threshold: 100 }, then set the key. For >= 80% (and < 100%): same pattern with key `budget_alert_{year}_{month}_80`, title "Budget warning", body "{householdName} has used 80% of the monthly budget (${Math.round(monthlyTotal)} of ${budgetTarget}).".

4. Create `supabase/migrations/00013_create_push_tokens.sql`:
   ```sql
   CREATE TABLE push_tokens (
     id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
     user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
     expo_push_token TEXT NOT NULL,
     device_id TEXT,
     platform TEXT DEFAULT 'ios',
     created_at TIMESTAMPTZ DEFAULT now(),
     updated_at TIMESTAMPTZ DEFAULT now(),
     UNIQUE(user_id, expo_push_token)
   );

   ALTER TABLE push_tokens ENABLE ROW LEVEL SECURITY;

   CREATE POLICY "Users can read own tokens"
     ON push_tokens FOR SELECT USING (auth.uid() = user_id);
   CREATE POLICY "Users can insert own tokens"
     ON push_tokens FOR INSERT WITH CHECK (auth.uid() = user_id);
   CREATE POLICY "Users can update own tokens"
     ON push_tokens FOR UPDATE USING (auth.uid() = user_id);
   CREATE POLICY "Users can delete own tokens"
     ON push_tokens FOR DELETE USING (auth.uid() = user_id);

   CREATE INDEX idx_push_tokens_user_id ON push_tokens(user_id);
   ```
