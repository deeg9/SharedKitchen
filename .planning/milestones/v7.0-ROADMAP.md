Implement 14 Google Stitch UI designs across all major app surfaces — preserving all existing functionality while elevating the visual design to match the Stitch reference screens, constrained by the existing SharedKitchen design system.

## Key Decisions

- Stitch designs used as visual references only — all code hand-written in React Native
- Existing design tokens override Stitch color/typography/spacing choices
- Tab bar (5 tabs), FAB style, and "SharedKitchen" branding preserved
- Day/Week toggle is local useState (not planStore) — UI preference only
- Budget category split hardcoded 60/25/15 (Groceries/Dining Out/Takeout)
- Cooking streak = consecutive days backwards from today with 1+ meal planned
- Yearly Stripe price_id deferred — CTA shows "Coming Soon"

## Tech Debt

- Yearly Stripe pricing tier non-functional (no price_id)
- Recipe description field absent (uses first instruction text)
- Budget category split not user-configurable
- Dark Mode toggle cosmetic only
- Human verification items for animations, visual fidelity, and navigation flows
