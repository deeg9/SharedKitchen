  <action>
The FilterBar component sets `zIndex: 10` on its container for its own dropdown overlay system. This causes the FilterBar to render above the @gorhom/bottom-sheet backdrop when the MealGeneratorSheet opens, because they are in the same view hierarchy.

The fix: Wrap the FilterBar in RecipeGrid.tsx with a View that has `zIndex: 1` and set `position: 'relative'` to create a new stacking context. This contains the FilterBar's z-index within its parent, preventing it from escaping above sibling components like the BottomSheet backdrop.

In `RecipeGrid.tsx`, wrap the `<FilterBar />` call (around line 62) with:
```tsx
<View style={{ zIndex: 1, position: 'relative' }}>
  <FilterBar />
</View>
```

This creates a stacking context -- FilterBar's internal `zIndex: 10` is now relative to this wrapper (value 1), not the root. The @gorhom/bottom-sheet renders at a higher level, so it paints above this contained z-stack.

Do NOT modify FilterBar.tsx itself -- the dropdown z-index logic inside it works correctly for its own purposes. Only wrap it in RecipeGrid.tsx.
