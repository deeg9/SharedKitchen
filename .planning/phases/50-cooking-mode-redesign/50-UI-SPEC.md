| Property | Value |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, ingredient row vertical padding, badge vertical padding, progress bar segment gap |
| sm | 8px | Compact element spacing, header vertical padding, badge horizontal padding |
| md | 16px | Default element spacing, horizontal padding, bottom nav padding |
| lg | 24px | Section padding, step card horizontal padding, tip/ingredient card margins |
| xl | 32px | Not used in this phase |
| xxl | 48px | Not used in this phase |

Exceptions: Touch targets for navigation buttons must be minimum 44px height for accessibility (iOS HIG). Close button is 40x40px (existing pattern, acceptable for icon-only with generous hit area).

## Interaction Contract

### Step Navigation

| Interaction | Behavior |
|-------------|----------|
| Tap "Next Step" | Advance to next step, haptic feedback (selectionAsync) |
| Tap "Previous Step" | Go to previous step, haptic feedback (selectionAsync) |
| Tap "Done Cooking" (last step) | Trigger onCookComplete callback |
| Previous Step at step 0 | Button disabled, opacity 0.3 |
| Step transition | ScrollView re-keys on step change (key={`step-${currentStep}`}) |

### Step Categorization

| Keyword Group | Category |
|---------------|----------|
| chop, dice, mince, slice, peel, wash, rinse, measure, prep | PREP |
| grill, sear, char | GRILLING |
| simmer, boil, reduce | SIMMERING |
| bake, roast | BAKING |
| mix, combine, whisk | MIXING |
| marinat* | MARINATING |
| (no match) | COOK |

Matching is case-insensitive substring search on step text.

### Per-Step Ingredient Matching

| Rule | Detail |
|------|--------|
| Algorithm | Scan step text (lowercased) for ingredient name (lowercased) substring match |
| Minimum name length | 3 characters (skip very short ingredient names to avoid false matches) |
| Display | amount + unit + name per matched ingredient |
| Empty state | "No ingredients for this step" text placeholder |
| Unit conversion | Applies current unitSystem via convertAmount() from unit-conversion.ts |
