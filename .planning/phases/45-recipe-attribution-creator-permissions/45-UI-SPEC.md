## Layout Specifications

### Creator Attribution Row (recipe detail)

```
[Avatar(sm=32px)] [8px gap] [Text column]
                              "Created by @{handle}" (labelLg, primary)
```

- Positioned below recipe title, above rating pill
- Replaces existing plain text `by @{handle}` with avatar + formatted row
- Horizontal layout: `flexDirection: 'row'`, `alignItems: 'center'`, `gap: spacing.sm`
- Margin: `marginTop: -spacing.sm` (matches existing attribution margin), `marginBottom: spacing.md`
- Tappable: navigates to public profile on press

### Conditional Edit Button

- Edit button (pencil-outline icon, top-right header overlay) renders ONLY when `recipe.created_by === currentUser.id`
- Legacy recipes (`is_creator_owned === false`): show Edit button for all household members
- Non-creators: the pencil icon simply does not render; no tooltip, no disabled state

### Search Tab Bar (within KitchenSearchBar)

```
[Kitchens]  [People]
─────────────────────
```

- Two-tab segmented control below the search input row
- Tab style: `labelLg` text, horizontal `flexDirection: 'row'`
- Active tab: `primary` (#334537) text color, 2px bottom border in `primary`
- Inactive tab: `onSurfaceVariant` (#434843) text color, no border
- Tab container: `paddingHorizontal: spacing.md`, `paddingVertical: spacing.sm`, `borderBottomWidth: 1`, `borderBottomColor: colors.outlineVariant`
- Default active tab: Kitchens (preserves current behavior)

### People Search Result Row

```
[Avatar(sm=32px)] [8px gap] [Text column]
                              "@{handle}" (labelLg, onSurface)
                              "{display_name}" (bodyMd, onSurfaceVariant)
```

- Row: `flexDirection: 'row'`, `alignItems: 'center'`, `paddingHorizontal: spacing.md`, `paddingVertical: spacing.sm`
- Tappable: entire row is a Pressable, navigates to public profile
- Separator: 1px `outlineVariant` bottom border between results

### Public Profile Screen

```
┌─────────────────────────────┐
│ [<- Back]                   │  Safe area + spacing.xs top
│                             │
│      [Avatar(lg=64px)]      │  Centered
│      @{handle}              │  titleMd, primary, centered
│      {display_name}         │  bodyLg, onSurfaceVariant, centered
│                             │
│ ─────────────────────────── │  outlineVariant divider
│                             │
│  Recipes                    │  titleLg, left-aligned, paddingHorizontal: md
│                             │
│  [RecipeCard] [RecipeCard]  │  2-column grid, gap: spacing.sm
│  [RecipeCard] [RecipeCard]  │  FlatList with numColumns={2}
│                             │
│  {empty state if no public  │
│   recipes}                  │
└─────────────────────────────┘
```

- Header section: `alignItems: 'center'`, `paddingVertical: spacing.xl`, `backgroundColor: colors.surfaceContainer`
- Recipe grid: `paddingHorizontal: spacing.md`, cards use existing recipe card pattern
- Each recipe card: Image (aspect ratio 4:3), recipe name below in `labelLg`, `borderRadius: borderRadius.md`
- Back button: same floating button pattern as recipe detail (`headerBtn` style)

## Interaction Contracts

### Creator Attribution Tap

- Tap on CreatorAttribution row navigates to `/(app)/user/{creator_id}`
- Haptic feedback: none (standard navigation, no special emphasis)

### Search Tab Switching

- Tap Kitchens/People tab instantly switches content (no animation delay)
- Search query persists across tab switches (shared input field)
- Each tab runs its own debounced search (300ms, matching existing KitchenSearchBar)
- Results list resets when switching tabs

### People Search Result Tap

- Tap navigates to `/(app)/user/{user_id}`
- Keyboard dismisses on navigation
- Search query and results clear on navigation

### Edit Button Visibility

- No animation for showing/hiding -- button either renders or does not
- Loading state: while `recipe` is loading, Edit button does not render (existing skeleton behavior)
- After load: compare `recipe.created_by === currentUser.id` OR `recipe.is_creator_owned === false && userIsHouseholdMember`

## State Mapping

| State | Visual Treatment |
|-------|-----------------|
| Recipe loading | Existing skeleton, no Edit button, no CreatorAttribution |
| Recipe loaded, user is creator | Edit button visible (pencil-outline), CreatorAttribution row with own handle |
| Recipe loaded, user is NOT creator | No Edit button, CreatorAttribution row with creator's handle |
| Legacy recipe (is_creator_owned=false) | Edit button visible for all household members, CreatorAttribution shows assigned admin handle |
| Recipe with no created_by (edge case) | No CreatorAttribution row, Edit button visible for all household members |
| People search: empty query | No results shown, prompt text only |
| People search: loading | ActivityIndicator centered (matches existing KitchenSearchBar pattern) |
| People search: error | EmptyState: "Couldn't load results. Check your connection and try again." with retry button |
| People search: no results | EmptyState: "No people found" / "Try a different @handle or name" |
| People search: results found | FlatList of UserSearchResult rows |
| Public profile: loading | Skeleton for avatar + name, skeleton grid for recipes |
| Public profile: load error | EmptyState: "Couldn't load this profile. Check your connection and try again." with retry button |
| Public profile: loaded, has recipes | Recipe grid displayed |
| Public profile: loaded, no recipes | EmptyState with "No recipes yet" |
