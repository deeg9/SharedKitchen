  <action>
Create migration file `supabase/migrations/00026_recipe_attribution_rls.sql` with these steps IN ORDER (all in one transaction):

**Step 1 -- Backfill legacy recipes:**
```sql
UPDATE recipes r
SET created_by = COALESCE(
  (SELECT hm.user_id FROM household_members hm
   WHERE hm.household_id = r.household_id AND hm.role = 'admin'
   ORDER BY hm.joined_at ASC LIMIT 1),
  (SELECT hm.user_id FROM household_members hm
   WHERE hm.household_id = r.household_id
   ORDER BY hm.joined_at ASC LIMIT 1)
)
WHERE r.created_by IS NULL;
```
The COALESCE handles edge case where a household has no admin -- falls back to oldest member.

**Step 2 -- Drop old permissive UPDATE and DELETE policies:**
```sql
DROP POLICY IF EXISTS "Users can update recipes in their household" ON recipes;
DROP POLICY IF EXISTS "Users can delete recipes in their household" ON recipes;
```
Do NOT drop SELECT or INSERT policies -- those remain unchanged.

**Step 3 -- Create creator-only UPDATE policy with legacy exception:**
```sql
CREATE POLICY "Creator can update own recipes"
  ON recipes FOR UPDATE
  USING (
    auth.uid() = created_by
    OR (
      is_household_member(household_id, auth.uid())
      AND created_by = (
        SELECT hm.user_id FROM household_members hm
        WHERE hm.household_id = recipes.household_id
        AND hm.role = 'admin'
        ORDER BY hm.joined_at ASC
        LIMIT 1
      )
    )
  );
```
The legacy exception: if the recipe's created_by equals the household admin (meaning it was a legacy recipe assigned during backfill), any household member can still edit it.

**Step 4 -- Create creator-only DELETE policy (same logic):**
```sql
CREATE POLICY "Creator can delete own recipes"
  ON recipes FOR DELETE
  USING (
    auth.uid() = created_by
    OR (
      is_household_member(household_id, auth.uid())
      AND created_by = (
        SELECT hm.user_id FROM household_members hm
        WHERE hm.household_id = recipes.household_id
        AND hm.role = 'admin'
        ORDER BY hm.joined_at ASC
        LIMIT 1
      )
    )
  );
```
