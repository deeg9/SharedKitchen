| md | 16px | Default element spacing, section padding |
| lg | 24px | Section padding, bottom sheet internal padding |

### Cook Count Badge (recipe detail)

```

```

```
[Photo 1] [Photo 2] [Photo 3] ...  (horizontal scroll)
  2d ago     1w ago    3w ago
  @alice     @bob      @alice
```

- Horizontal FlatList below ingredients section, above comments (Phase 47)
- Section heading: "Cook Photos" in `titleMd`, `paddingHorizontal: spacing.md`, `marginBottom: spacing.sm`
- Each thumbnail: 80px x 80px, `borderRadius: borderRadius.sm` (8px)

- Overlay text: date on first line, @handle on second line, both `labelMd`, `color: colors.inverseOnSurface`
- Empty state: entire gallery section is hidden (no heading, no empty row)
- Tappable: opens full-screen image viewer (standard expo-image or modal)

## Interaction Contracts

### "I Cooked This" Button Tap

- Tap opens CookLogSheet bottom sheet
- Button disabled while sheet is open (prevent double-open)
- Haptic feedback: light impact on tap

### Cook Log Bottom Sheet Flow

1. Sheet opens with empty state (no photo, no note)
2. User taps "Add Photo" to open CameraSheet (camera or gallery picker)
3. After photo selection, thumbnail appears in photo area; X button allows removal
4. User optionally types a note
5. User taps "Log Cook" to submit
6. On submit: button shows ActivityIndicator, inputs become non-interactive
7. On success: sheet closes, CookCountBadge increments, photo appears in gallery (optimistic update)
8. On failure: error toast appears ("Couldn't save your cook log..."), button re-enables

### Post-Cooking-Mode Prompt

- After CookingMode `onClose` fires, CookLogSheet opens automatically with 500ms delay
- Sheet shows additional body text: "You just finished cooking! Add a photo and note."
- User can dismiss (swipe down) without logging
- If user dismisses, no cook log is created (cook logs are prompt-only, never auto-created)

### Past Meal Banner Interaction

- Banner appears on Plan tab when yesterday has meal plan entries with no corresponding cook log
- "Yes" taps: opens CookLogSheet pre-filled with the recipe context
- "Skip" taps: dismisses banner for that specific meal (persisted locally, do not show again for that meal+date)
- Banners only show for meals from yesterday (not older)
- After logging via "Yes", banner auto-dismisses for that meal

### Photo Gallery Thumbnail Tap

- Tap opens full-screen image viewer (modal overlay)
- Swipe to dismiss or tap close button
- No edit/delete from gallery view (delete is via long-press on own cook logs)

### Delete Cook Log (own logs only)

- Long-press on own cook log thumbnail in gallery shows confirmation alert
- Alert title: "Delete cook log"
- Alert message: "This will remove the cook log and photo. This can't be undone."
- Alert buttons: "Cancel" (default) / "Delete" (destructive, red text)
- On confirm: log and photo removed, count badge decrements, thumbnail removed from gallery

## State Mapping

| State | Visual Treatment |
|-------|-----------------|
| Recipe loading | Existing skeleton, no CookLogButton, no badge, no gallery |
| Recipe loaded, 0 cooks | CookLogButton visible, badge shows "Not cooked yet" in muted text, gallery section hidden |
| Recipe loaded, 1+ cooks, no photos | CookLogButton visible, badge shows "Cooked N times", gallery section hidden (no photos to show) |
| Recipe loaded, 1+ cooks, with photos | CookLogButton visible, badge shows "Cooked N times", gallery section visible with thumbnails |
| CookLogSheet: empty | Photo placeholder (dashed border), empty notes input, "Log Cook" button enabled |
| CookLogSheet: photo selected | Photo thumbnail with X remove button, notes input, "Log Cook" button enabled |
| CookLogSheet: submitting | Photo and notes non-interactive, "Log Cook" shows spinner, button disabled |
| CookLogSheet: error | Error toast shown, form re-enabled for retry |
| Post-cooking-mode prompt | CookLogSheet opens with extra body text, same form fields |
| Past meal banner: pending | Banner visible at top of Plan tab |
| Past meal banner: logging | "Yes" button shows spinner, "Skip" disabled |
| Past meal banner: dismissed | Banner removed from view for that meal |
| Photo gallery: loading | Skeleton rectangles (80x80) in horizontal scroll |
| Photo gallery: loaded | Thumbnails with date/@handle overlays |
| Full-screen photo viewer | Modal overlay with photo, dark background, close button top-right |
| Delete confirmation | Native Alert dialog with Cancel and Delete buttons |
