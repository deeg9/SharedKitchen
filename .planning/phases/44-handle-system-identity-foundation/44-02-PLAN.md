  - Heading: "Choose your handle" in `headlineMd`, `onSurface` color
  - Body: "Pick a unique @username that identifies you across SharedKitchen." in `bodyLg`, `onSurfaceVariant` color, `spacing.sm` (8px) below heading
  - HandleInput: `spacing.lg` (24px) below body
  - HandleSuggestions: `spacing.md` (16px) below input
  - CTA pinned to bottom with `spacing.xl` (32px) from safe area bottom: full width, 48px height, `borderRadius.md` (12px)

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-01 | Tampering | HandleInput | mitigate | Client-side validateHandle() strips invalid chars + regex validation; DB CHECK constraint `chk_handle_format` is final arbiter |
| T-44-02 | Tampering | HandleSetupInterstitial | mitigate | Race condition on claim handled by catching Postgres 23505 error in authStore.updateHandle() with user-friendly retry message |
| T-44-03 | Denial of Service | HandleInput availability check | accept | Debounced to 400ms; Supabase has built-in rate limiting; low-value target |
| T-44-04 | Elevation of Privilege | HandleSetupInterstitial | mitigate | Rendered as full-screen overlay with zIndex 9999 and accessibilityViewIsModal; no navigation escape routes; handle null check prevents bypass |
| T-44-05 | Information Disclosure | Handle availability check | accept | Reveals whether a handle exists; acceptable trade-off for core UX per research |
