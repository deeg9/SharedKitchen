**File 1: `src/lib/food-api.ts`**

Create the client-side wrapper for the food-search Edge Function.

1. Import `supabase` from the existing supabase client (find the import path used by other lib files like `src/lib/vision.ts` or `src/lib/ai.ts`).
2. Import `FoodSearchResult`, `FoodItem`, `NutritionData` from `../types/food`.

3. Create `SearchLimitError` class extending Error:
   ```typescript
   export class SearchLimitError extends Error {
     limit: number;
     used: number;
     constructor(message: string, limit: number, used: number) {
       super(message);
       this.name = 'SearchLimitError';
       this.limit = limit;
       this.used = used;
     }
   }
   ```

4. Create `searchFoods(query: string): Promise<FoodSearchResult[]>` that:
   - Calls `supabase.functions.invoke('food-search', { body: { query } })`
   - On error, checks `(error as any).context` for body -- if `body.type === 'search_limit_exceeded'`, throw `SearchLimitError(body.error, body.limit, body.used)`
   - Otherwise throw `new Error(body?.error ?? 'Food search failed')`
   - Returns `data?.results ?? []`

5. Create `getFoodDetail(foodId: string): Promise<FoodItem | null>` that:
   - Calls `supabase.from('food_items').select('*').eq('id', foodId).maybeSingle()`
   - Returns `data` or null on error

interface FoodStoreState {
  query: string;
  results: FoodSearchResult[];
  loading: boolean;
  error: string | null;
  rateLimited: boolean;
  expandedItemId: string | null;

Actions:
- `setQuery(query)` -- just sets the query string (UI controls debounce)
- `searchFoods(query)` -- sets loading=true, calls `searchFoods` from food-api, sets results on success, catches `SearchLimitError` and sets `rateLimited=true` + appropriate error message, catches other errors and sets error message, always sets loading=false
- `clearResults()` -- resets results, error, rateLimited to defaults
- `toggleExpanded(itemId)` -- if `expandedItemId === itemId`, collapse (set null). Otherwise set `expandedItemId = itemId`, set `detailLoading = true`, call `getFoodDetail(itemId)`, set `expandedItemDetail` and `detailLoading = false`
- `reset()` -- reset all state to defaults
