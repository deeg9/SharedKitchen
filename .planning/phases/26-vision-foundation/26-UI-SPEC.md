# Phase 26 — UI Design Contract

> Visual and interaction contract for Vision Foundation. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (React Native StyleSheet) |
| Preset | not applicable |
| Component library | @gorhom/bottom-sheet, custom ui/ components |
| Icon library | @expo/vector-icons (MaterialCommunityIcons) |
| Font | Plus Jakarta Sans (headlines), Inter (body/labels) |

**Note:** Project uses a mature Culinary Curator design system at `src/theme/` with colors, typography, spacing, borderRadius, and shadows modules. All new components must import from these modules. No hex values outside `theme/colors.ts`.

## Spacing Scale

Declared values (all multiples of 4, sourced from `src/theme/spacing.ts`):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, list item vertical padding |
| md | 16px | Default element spacing, horizontal padding |
| lg | 24px | Section padding, content margins |
| xl | 32px | Layout gaps, large button horizontal padding |
| xxl | 48px | Major section breaks |

Border radius (from `src/theme/spacing.ts`):

| Token | Value | Usage |
|-------|-------|-------|
| sm | 8px | Small elements, badges |
| md | 12px | Cards, list items |
| lg | 16px | Buttons, containers |
| xl | 24px | Bottom sheet corners |
| full | 9999px | FAB, circular elements, avatars |

Exceptions:
- Camera FAB: 56x56px (existing pattern from OnHandList), positioned `right: spacing.md` and `bottom: TAB_BAR_HEIGHT + spacing.md`
- Camera FAB touch target is 56px (exceeds 44px minimum)

## Component Inventory

New components this phase must create:

### 1. CameraSheet (bottom sheet)
- **Location:** `src/components/camera/CameraSheet.tsx`
- **Pattern:** Uses existing `BottomSheet` wrapper from `src/components/ui/BottomSheet.tsx`
- **Snap points:** `['35%']`
- **Layout:** Vertical stack, centered
  - Handle bar (inherited from BottomSheet)
  - Heading: "Add a Photo" (typography.titleMd, colors.onSurface)
  - Two option rows, each as a Pressable:
    - Row 1: camera icon + "Take Photo" (labelLg) + "Use your camera" (bodyMd, onSurfaceVariant)
    - Row 2: image icon + "Choose from Gallery" (labelLg) + "Select an existing photo" (bodyMd, onSurfaceVariant)
  - Each row: `paddingVertical: spacing.md`, `paddingHorizontal: spacing.lg`, `borderRadius: borderRadius.md`, highlight on press with `surfaceContainerHigh`
- **Icon specs:** MaterialCommunityIcons, "camera" and "image-multiple", size 24, color primary
- **Spacing:** `spacing.md` gap between rows, `spacing.lg` horizontal padding

### 2. CameraPermissionCard (inline recovery)
- **Location:** `src/components/camera/CameraPermissionCard.tsx`
- **When shown:** Camera permission is denied (replaces camera sheet content or shown inline on Kitchen tab)
- **Layout:** Horizontal card
  - Left: MaterialCommunityIcons "camera-off-outline", size 32, color onSurfaceVariant
  - Center: "Camera access needed" (titleMd) + "Open Settings to allow SharedKitchen to use your camera" (bodyMd, onSurfaceVariant)
  - Right: Button variant="secondary", size="sm", label "Open Settings"
- **Container:** `backgroundColor: surfaceContainerLow`, `borderRadius: borderRadius.lg`, `padding: spacing.md`, `marginHorizontal: spacing.md`

### 3. CameraPermissionPrompt (pre-prompt bottom sheet)
- **Location:** `src/components/camera/CameraPermissionPrompt.tsx`
- **Pattern:** Follows existing `PermissionPrompt.tsx` from notifications exactly
- **Layout:** Modal bottom sheet (same as notifications), centered content:
  - Icon circle: 80x80px, `borderRadius: 40`, `backgroundColor: #f0f5f0` (matches notification prompt), MaterialCommunityIcons "camera-outline" size 48, color primary
  - Title: "Scan food with your camera" (titleLg, color primary, centered)
  - Benefits list (3 rows, same BenefitRow pattern):
    - "camera-outline": "Photograph your fridge or pantry to add items instantly"
    - "food-variant": "Snap a photo of food to find matching recipes"
    - "calendar-check-outline": "Log meals to your plan with a quick photo"
  - CTA: "Allow Camera" button (full-width, primary background, borderRadius.lg, paddingVertical 16)
  - Dismiss: "Not Now" text button (bodyMd, onSurfaceVariant)

### 4. VisionLoadingOverlay (processing state)
- **Location:** `src/components/camera/VisionLoadingOverlay.tsx`
- **When shown:** After photo captured, while Edge Function processes image
- **Layout:** Full-screen semi-transparent overlay (`rgba(0,0,0,0.5)`) with centered card:
  - Card: `surfaceContainerLowest` background, `borderRadius.xl`, `padding: spacing.xl`
  - ActivityIndicator, size "large", color primary
  - Text: "Analyzing photo..." (titleMd, onSurface, centered)
  - Sub-text: "This usually takes a few seconds" (bodyMd, onSurfaceVariant, centered)
  - Spacing: `spacing.md` between spinner and text, `spacing.xs` between text and sub-text

### 5. Camera FAB (on Kitchen tab)
- **Location:** Added to Kitchen tab screen (not a separate component file -- inline in kitchen.tsx)
- **Spec:** Identical to existing add-pantry-fab in OnHandList:
  - 56x56px, `borderRadius.full`, `backgroundColor: primary`, `shadows.float`
  - Position: `absolute`, `right: spacing.md`, `bottom: TAB_BAR_HEIGHT + spacing.md`
  - Icon: MaterialCommunityIcons "camera" size 28, color onPrimary
  - testID: "camera-fab"
- **Interaction:** On press, check camera permission via `useCameraPermission` hook. If undetermined and pre-prompt not shown, open CameraPermissionPrompt. If granted, open CameraSheet. If denied, show CameraPermissionCard.

## Interaction States

### Camera FAB
| State | Visual |
|-------|--------|
| Default | primary background, float shadow, camera icon |
| Pressed | opacity 0.85 (matches existing Button pressed style) |
| Disabled (during processing) | opacity 0.5 |

### CameraSheet Options
| State | Visual |
|-------|--------|
| Default | transparent background |
| Pressed | surfaceContainerHigh background |
| Disabled | not applicable (always enabled) |

### Vision Processing
| State | Visual |
|-------|--------|
| Loading | VisionLoadingOverlay with ActivityIndicator |
| Success | Overlay dismisses, result passed to caller (Phase 27-29 handles display) |
| Error (generic) | Alert with title + retry option |
| Error (rate limit) | Rate limit card shown inline |

### Camera Permission
| State | Visual |
|-------|--------|
| Undetermined (first time) | CameraPermissionPrompt bottom sheet |
| Undetermined (prompt shown before) | System dialog directly |
| Granted | CameraSheet opens |
| Denied | CameraPermissionCard shown inline |
