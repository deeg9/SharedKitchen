**Create `src/components/barcode/BarcodeResultCard.tsx`:**

A modal/overlay card shown after a barcode scan resolves to a product. Props:
```typescript
interface BarcodeResultCardProps {
  food: FoodItem;
  visible: boolean;
  onClose: () => void;
  onAddedToPantry: () => void;
  onAddedToGrocery: () => void;
}
```

Layout (per CONTEXT decisions -- product card with nutrition + dual action buttons):
- Full-screen semi-transparent backdrop (rgba(0,0,0,0.5)) with centered card (white, rounded corners, ~90% width, max 500px)
- **Product header:** food.image_url displayed as a small thumbnail (48x48) if available (use expo-image Image component), product name (typography.titleMd), brand below in onSurfaceVariant if present
- **Nutrition row:** Horizontal row of 4 macro pills (same style as FoodSearchSheet macro pills if that pattern exists, otherwise simple rounded containers): Calories (kcal), Protein (g), Carbs (g), Fat (g) -- values from food.nutrition per 100g
- **Duplicate detection:** On mount, check `usePantryStore.getState().items` for any item whose `name.toLowerCase()` includes `food.name_normalized` or vice versa. If found, show an amber "Already in pantry" badge above the action buttons.
- **Action buttons:** Two side-by-side buttons at the bottom of the card:
  - "Add to Pantry" (primary filled button, MaterialCommunityIcons "fridge-outline") -- calls `usePantryStore.getState().addPantryItem(activeHouseholdId, { name: food.name, category: food.category ?? 'Other' })`. On success, show toast "Added to Pantry" (use Alert.alert as existing toast pattern), then call onAddedToPantry.
  - "Add to Grocery" (outlined button, MaterialCommunityIcons "cart-plus") -- calls `useGroceryStore.getState().addManualItem(activeListId, food.name, '1', food.category ?? 'Other')`. If no activeListId, show alert "No active grocery list. Generate one from the Shopping List tab first." On success, show toast "Added to Grocery List", then call onAddedToGrocery.
- **Close button:** X button at top-right of the card.
