**Edge Function `supabase/functions/food-barcode/index.ts`:**

Create a new Edge Function that accepts `{ barcode: string }` in the request body. Follow the exact same patterns from `food-search/index.ts` for CORS headers, user auth, admin client, and rate limiting (reuse `food-search` function_name in ai_usage_log so barcode scans share the 20/day free limit with searches).

Barcode normalization: If the barcode is 12 digits (UPC-A), prepend "0" to convert to EAN-13 before lookups. Store both original and normalized forms.

**Cache-first lookup:** Before external APIs, check `food_items` table for `barcode = normalizedBarcode` with `expires_at > now()`. If found, return the cached FoodItem directly.

**API lookup order (per D: Open Food Facts first, FatSecret fallback):**

1. **Open Food Facts** (free, no auth): `GET https://world.openfoodfacts.org/api/v2/product/{barcode}.json` with `User-Agent: SharedKitchen/1.0 (contact@sharedkitchen.app)` header. Check `response.status === 1` for success. Normalize the OFF product to our FoodItem format:
   - `name` = product.product_name (fall back to product.generic_name)
   - `brand` = product.brands
   - `barcode` = normalizedBarcode
   - `off_barcode` = normalizedBarcode
   - `image_url` = product.image_url
   - `category` = first item of product.categories_tags (remove "en:" prefix)
   - Nutrition from product.nutriments: `energy-kcal_100g` -> calories, `proteins_100g` -> protein_g, `fat_100g` -> total_fat_g, `carbohydrates_100g` -> total_carbs_g, `sodium_100g` * 1000 -> sodium_mg (OFF stores sodium in grams), `saturated-fat_100g` -> saturated_fat_g, `fiber_100g` -> dietary_fiber_g, `sugars_100g` -> total_sugars_g
   - `source` = 'off', `data_quality` = 75

2. **FatSecret fallback** (if OFF returned no result or status !== 1): Reuse the `getFatSecretToken()` OAuth2 pattern from food-search. Call `food.find_id_for_barcode` method: `GET https://platform.fatsecret.com/rest/food/barcode/find-id/v1?barcode={barcode}&format=json` with Bearer token. If it returns a `food_id`, then call `GET https://platform.fatsecret.com/rest/food/v4?food_id={food_id}&format=json&include_food_images=true` to get full details. Normalize using the same `normalizeFatSecretFood` pattern from food-search, adding `barcode = normalizedBarcode`.

3. If both fail, return `{ found: false, barcode: normalizedBarcode }` with status 200 (not an error -- the product card will handle "not found" gracefully).

**On success:** Upsert the normalized result into `food_items` table (on conflict by barcode), then return `{ found: true, food: FoodItem }` where FoodItem includes the generated UUID from the upsert.

Apply 10-second timeout per external API call using AbortController (same pattern as food-search).

- `clearScan(): void` -- resets scannedProduct, scanLoading, scanError, scanNotFound to defaults.
