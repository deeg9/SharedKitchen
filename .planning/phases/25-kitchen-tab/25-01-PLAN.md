   ```sql
   create table pantry_items (
     id uuid primary key default gen_random_uuid(),
     household_id uuid references households(id) on delete cascade not null,
     name text not null,
     quantity text,
     unit text,
     category text default 'Other',
     added_at timestamptz default now(),
     expires_at date,
     created_by uuid references auth.users(id),
     source_grocery_item_id uuid references grocery_items(id) on delete set null
   );
   create index idx_pantry_items_household on pantry_items(household_id);
   alter table pantry_items enable row level security;
   ```

  <action>
1. Create `src/stores/pantryStore.ts` following groceryStore pattern:
   - State: items (PantryItem[]), loading (boolean), error (string|null)
   - Actions:
     - `fetchPantryItems(householdId: string)` — select from pantry_items where household_id, order by added_at desc
     - `addPantryItem(householdId: string, item: { name: string; quantity?: string; unit?: string; category?: string; expires_at?: string })` — insert into pantry_items, optimistic add to items array
     - `updatePantryItem(itemId: string, updates: Partial<PantryItemUpdate>)` — optimistic update with revert on error
     - `removePantryItem(itemId: string)` — optimistic delete with revert on error
     - `addFromGrocery(householdId: string, groceryItem: { name: string; quantity: string | null; section: string | null }, groceryItemId: string)` — insert pantry_item with source_grocery_item_id set, category mapped from grocery section
   - Realtime helpers: `_addItem`, `_updateItem`, `_removeItem` (same pattern as groceryStore)
   - `clear()` to reset state

2. Create `src/hooks/usePantrySync.ts` following useGrocerySync pattern exactly:
   - Takes `householdId: string | null` as parameter
   - Subscribes to `postgres_changes` on `pantry_items` table filtered by household_id (NOT by a list ID -- pantry is household-scoped)
   - Channel name: `pantry-items-${householdId}`
   - Handles INSERT -> `_addItem`, UPDATE -> `_updateItem`, DELETE -> `_removeItem`
   - Returns `{ status: SubscriptionStatus }`
   - Cleanup on unmount or householdId change
  </action>
