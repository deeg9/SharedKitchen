<!-- Root cause: @supabase/supabase-js v2.100.0 GenericTable requires Relationships field -->

From node_modules/@supabase/supabase-js (GenericSchema and GenericTable):
```typescript
type GenericTable = {
  Row: Record<string, unknown>;
  Insert: Record<string, unknown>;
  Update: Record<string, unknown>;
  Relationships: GenericRelationship[];  // <-- MISSING from current database.ts
};

type GenericView = GenericUpdatableView | GenericNonUpdatableView;
// Both require: Relationships: GenericRelationship[];

type GenericSchema = {
  Tables: Record<string, GenericTable>;
  Views: Record<string, GenericView>;
  Functions: Record<string, GenericFunction>;
};
```

The SupabaseClient resolves Schema as:
```typescript
Schema extends (Database[SchemaName] extends GenericSchema ? Database[SchemaName] : never)
```

Since current table definitions lack `Relationships`, they don't satisfy `GenericTable`,
so `Database['public']` doesn't satisfy `GenericSchema`, and `Schema` = `never`.
This cascades to ALL `.from()` return types resolving to `never`.
