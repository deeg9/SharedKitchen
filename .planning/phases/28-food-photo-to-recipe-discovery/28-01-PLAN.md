<task type="auto">
  <name>Task 1: Types and search-recipes Edge Function</name>
  <files>src/types/recipeSearch.ts, supabase/functions/search-recipes/index.ts</files>
  <read_first>supabase/functions/analyze-food-photo/index.ts, src/lib/vision.ts</read_first>
  <action>
1. Create `src/types/recipeSearch.ts` with:
   - `DishIdentification` interface: `{ name: string; confidence: number; description?: string }`
   - `RecipeSearchResult` interface: `{ title: string; url: string; source: string; thumbnail?: string; cookTime?: string }`

2. Create `supabase/functions/search-recipes/index.ts` following the exact same pattern as `analyze-food-photo/index.ts`:
   - CORS headers (same corsHeaders object)
   - OPTIONS preflight handler
   - Auth via `supabaseClient.auth.getUser()` with 401 on failure
   - Admin client with service_role for DB writes
   - Accept POST body: `{ query: string }` — the dish name to search for
   - Validate query is non-empty string, 400 if missing
   - Rate limit: check `ai_usage_log` for `function_name = 'search-recipes'` this month, limit 20/month free, unlimited premium (same premium check pattern as analyze-food-photo)
   - Call Serper.dev Google Search API:
     ```
     POST https://google.serper.dev/search
     Headers: { "X-API-KEY": Deno.env.get("SERPER_API_KEY"), "Content-Type": "application/json" }
     Body: { "q": `${query} recipe`, "num": 5 }
     ```
   - Parse Serper response `organic` array, map to RecipeSearchResult format:
     - `title`: result.title
     - `url`: result.link
     - `source`: extract domain from URL via `new URL(link).hostname.replace('www.', '')`
     - `thumbnail`: result.thumbnail ?? null (Serper may not return this for all results)
     - `cookTime`: null (not available from search results)
   - Filter results to max 3, skip results where URL does not look like a recipe page (skip if domain is youtube.com, tiktok.com, instagram.com — those are video, not recipe pages)
   - Log usage to `ai_usage_log`: `{ user_id, function_name: 'search-recipes', input_hash: null, cached_response: null, tokens_used: 0 }`
   - Return JSON: `{ results: RecipeSearchResult[] }`
   - On Serper error: return 502 with `{ error: "Recipe search failed. Please try again." }`
   - 30s timeout on Serper fetch via AbortController (same pattern as Gemini call in analyze-food-photo)
  </action>

Create `src/lib/recipeSearch.ts` following the exact same pattern as `analyzePhoto` in `src/lib/vision.ts`:

1. Import `RecipeSearchResult` from `../types/recipeSearch`
2. Import `supabase` from `./supabase`
3. Import `RateLimitError` from `./ai` (reuse existing class)

4. Export `async function searchRecipes(dishName: string): Promise<RecipeSearchResult[]>`:
   - Get auth session: `const session = await supabase.auth.getSession()`
   - Extract token, supabaseUrl, anonKey (same pattern as vision.ts)
   - POST to `${supabaseUrl}/functions/v1/search-recipes` with:
     - Headers: Content-Type, Authorization Bearer token, apikey
     - Body: `JSON.stringify({ query: dishName })`
   - Parse JSON response
   - If !response.ok:
     - If 429: throw `new RateLimitError('Monthly recipe search limit reached', data.limit ?? 20, 0)`
     - Otherwise: throw `new Error(data.error ?? 'Recipe search failed')`
   - Return `data.results as RecipeSearchResult[]`
  </action>
