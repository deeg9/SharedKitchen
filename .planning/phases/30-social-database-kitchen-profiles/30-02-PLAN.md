Create `src/stores/socialStore.ts` following the exact Zustand pattern from householdStore.ts.

**Store interface:**
```typescript
interface SocialState {
  // Profile being viewed (another kitchen's profile)
  viewedProfile: KitchenProfileWithRecipeCount | null;
  // Current user's kitchen profile (for active household)
  myKitchenProfile: KitchenProfile | null;
  // Search
  searchResults: KitchenProfile[];
  searchLoading: boolean;
  // General
  loading: boolean;
  error: string | null;

  // Actions
  fetchKitchenProfile: (kitchenId: string) => Promise<void>;
  fetchMyKitchenProfile: (householdId: string) => Promise<void>;
  getOrCreateKitchenProfile: (householdId: string, householdName: string) => Promise<KitchenProfile | null>;
  updateKitchenProfile: (kitchenId: string, updates: KitchenProfileUpdate) => Promise<void>;
  searchKitchens: (query: string) => Promise<void>;
  clearSearch: () => void;
  clearViewedProfile: () => void;
}
```

**fetchKitchenProfile(kitchenId):**
- Query `kitchen_profiles` by id, select all columns
- Then query `recipes` table: `select('id', { count: 'exact', head: true }).eq('household_id', data.household_id)`
- Set `viewedProfile` with recipe_count merged in
- Handle error via getErrorMessage

**fetchMyKitchenProfile(householdId):**
- Query `kitchen_profiles` by household_id
- If no result, do NOT auto-create (getOrCreateKitchenProfile is the explicit lazy-create method)
- Set `myKitchenProfile`

**getOrCreateKitchenProfile(householdId, householdName):**
- First try to fetch by household_id
- If exists, set myKitchenProfile and return it
- If not, insert new kitchen_profiles row: `{ household_id: householdId, display_name: householdName }`
- Set myKitchenProfile and return the created row
- This is the lazy creation pattern from RESEARCH.md Pitfall 3

**updateKitchenProfile(kitchenId, updates):**
- Update kitchen_profiles row, set updated_at to now()
- Re-fetch and update myKitchenProfile in state

**searchKitchens(query):**
- If query is empty/whitespace, clear results and return
- Set searchLoading: true
- Query: `.from('kitchen_profiles').select('id, display_name, bio, avatar_url, follower_count').eq('is_searchable', true).ilike('display_name', '%${query}%').limit(20)`
- Set searchResults and searchLoading: false

**clearSearch():** Reset searchResults to [], searchLoading to false
**clearViewedProfile():** Reset viewedProfile to null

Export as `useSocialStore`.
