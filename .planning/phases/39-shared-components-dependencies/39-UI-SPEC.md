# Phase 39 — UI Design Contract

> Visual and interaction contract for the 5 shared UI primitives: DonutChart, ProgressBar, InsightCard, FilterChips, DateStrip. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (React Native — shadcn not applicable) |
| Preset | not applicable |
| Component library | react-native core + react-native-svg + react-native-reanimated |
| Icon library | @expo/vector-icons (MaterialCommunityIcons) |
| Font | Plus Jakarta Sans (headlines), Inter (body/labels) |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, chip internal padding |
| md | 16px | Default element spacing, card padding, section padding |
| lg | 24px | Section padding, component outer margins |
| xl | 32px | Layout gaps between major sections |
| xxl | 48px | Major section breaks |

Exceptions: DonutChart internal label uses 0 spacing (center-aligned via absolute positioning). DateStrip day cells use 44px minimum touch target width.

## Interaction Contracts

| Component | Interaction | Behavior |
|-----------|-------------|----------|
| DonutChart | Mount | Arc animates from 0 to target value over 800ms |
| DonutChart | Value change | Arc smoothly transitions to new value over 600ms |
| DonutChart | Tap | No interaction (display only) |
| ProgressBar | Mount | Fill width animates from 0 to target over 600ms |
| ProgressBar | Value change | Fill width smoothly transitions over 400ms |
| ProgressBar | Tap | No interaction (display only) |
| InsightCard | Tap | If onPress provided, opacity feedback (0.7) and callback. Otherwise no interaction. |
| FilterChips | Tap chip | Immediate background + text color swap (no animation delay). Calls onSelect. |
| FilterChips | Scroll | Horizontal scroll with deceleration rate "fast" |
| DateStrip | Tap day | Immediate selection highlight. Calls onSelectDate. |
| DateStrip | Scroll | Horizontal scroll, snaps to nearest day cell (snapToInterval: 64 = 56 + 8) |
| DateStrip | Mount | Auto-scrolls to center today in view |

## Animation Specifications

### Default/Fallback Display Values

| Component | Zero/Empty State | Source |
|-----------|------------------|--------|
| DonutChart (value=0) | Empty ring (track only), label shows "$0", badge shows "0%" | Graceful zero state |
| ProgressBar (value=0) | Track only, no fill visible | Graceful zero state |
| ProgressBar (value >= max) | Full fill, clamped at 100% | Prevents overflow |
| InsightCard (no badge) | Badge area hidden, message takes full width | Optional prop |
| FilterChips (empty array) | Component renders nothing (height 0) | Defensive |
| DateStrip (no dates in range) | Component renders nothing | Defensive |
