Props interface (per UI-SPEC):

```typescript
interface DonutChartProps {
  value: number;
  max: number;
  label: string;          // e.g. "$426"
  sublabel: string;       // e.g. "of $600 spent"
  badgeLabel?: string;    // e.g. "71%" — omit to hide badge

}
```

**SVG ring math (include these exact calculations):**
```typescript
const radius = (size - strokeWidth) / 2;         // e.g. (160 - 12) / 2 = 74
const circumference = 2 * Math.PI * radius;       // e.g. 2 * PI * 74 = ~464.96
const ratio = Math.min(value / Math.max(max, 1), 1); // clamp 0-1, prevent div by 0
```

**Implementation requirements:**
- Named export `DonutChart` (no default export)
- Also export `DonutChartProps` type for consumers
- Import `Svg`, `Circle` from `react-native-svg`
- Create an animated Circle: `const AnimatedCircle = Animated.createAnimatedComponent(Circle)` where `Animated` is from `react-native-reanimated`
- Use `useSharedValue(0)` for the animated progress value
- On mount and when `value`/`max` changes, set `progress.value = withTiming(ratio, { duration: 800, easing: Easing.out(Easing.cubic) })`. For value changes after initial mount, use 600ms duration.
- Use `useAnimatedProps` returning `{ strokeDashoffset: circumference * (1 - progress.value) }`
- **SVG structure (inside a View with `width: size, height: size`):**
  1. `Svg` with `width={size}` `height={size}` `viewBox={\`0 0 ${size} ${size}\`}`
  2. Background track circle: `Circle` with `cx={size/2}`, `cy={size/2}`, `r={radius}`, `stroke={colors.surfaceContainerHigh}`, `strokeWidth={strokeWidth}`, `fill="none"`, `strokeLinecap="round"`
  3. Animated fill arc: `AnimatedCircle` with same cx/cy/r, `stroke={colors.primary}`, `strokeWidth={strokeWidth}`, `fill="none"`, `strokeLinecap="round"`, `strokeDasharray={circumference}`, `animatedProps={animatedProps}`, `rotation="-90"`, `origin={\`${size/2}, ${size/2}\`}`

- **Center label overlay (positioned absolutely over the SVG):**
  - Outer container: `position: 'absolute'`, `top: 0, left: 0, right: 0, bottom: 0`, `alignItems: 'center'`, `justifyContent: 'center'`
  - Label text: `...typography.headlineLg`, `color: colors.onSurface` — displays `label` prop
  - Sublabel text: `...typography.bodySm`, `color: colors.onSurfaceVariant` — displays `sublabel` prop
  - Badge (if `badgeLabel` provided): View with `backgroundColor: colors.primaryFixed`, `borderRadius: borderRadius.full`, `paddingVertical: spacing.xs` (4), `paddingHorizontal: spacing.sm` (8), `marginTop: spacing.xs` (4)
    - Badge text: `...typography.labelMd`, `color: colors.primary` — displays `badgeLabel`

- **Accessibility:** `accessibilityLabel={\`${label} ${sublabel}\`}` on the outer container
- **Zero state (value=0):** Shows empty ring (track only), label shows whatever is passed (e.g. "$0"), badge shows whatever is passed (e.g. "0%")
- Use `StyleSheet.create` for all static styles
- Use `useEffect` with `[value, max]` deps to trigger the shared value animation
