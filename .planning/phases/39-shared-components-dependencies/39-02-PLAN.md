Create `src/components/ui/DateStrip.tsx`.

Props interface (per UI-SPEC):
```typescript
interface DateStripProps {
  selectedDate: Date;
  onSelectDate: (date: Date) => void;
  startDate?: Date;           // default: Monday of current week
  endDate?: Date;             // default: Sunday of current week
}
```

Implementation requirements:
- Named export `DateStrip` (no default export)
- Also export `DateStripProps` type for consumers
- **Date range generation:** If `startDate`/`endDate` not provided, compute Monday-Sunday of the week containing `selectedDate`. Generate an array of Date objects for each day in the range.
- If the generated array is empty, return `null` (defensive per UI-SPEC)
- Outer container: `ScrollView` with `horizontal={true}`, `showsHorizontalScrollIndicator={false}`, `contentContainerStyle` with `paddingHorizontal: spacing.md` (16)
- `snapToInterval={64}` (56px cell + 8px gap per UI-SPEC), `decelerationRate="fast"`
- **Auto-scroll to today on mount:** Use `useRef<ScrollView>` and `useEffect` on mount. Find the index of today in the date array. Calculate scroll offset: `index * 64 - (layoutWidth / 2) + 32` (center today). Call `scrollViewRef.current?.scrollTo({ x: offset, animated: true })`. Use `onLayout` to capture the ScrollView width, or use a reasonable default of 300px and refine with `onLayout`.
- **Day cell layout:** `TouchableOpacity` for each day
  - Width: 56, Height: 68, `borderRadius: borderRadius.md` (12), `alignItems: 'center'`, `justifyContent: 'center'`, `marginRight: spacing.sm` (8)
  - `onPress` calls `onSelectDate(dayDate)`
  - **Default state:** `backgroundColor: 'transparent'`
  - **Selected (non-today):** `backgroundColor: colors.surfaceContainer`
  - **Today:** The date number gets a circle behind it
- **Day name text:** `Text` with `...typography.labelSm`, `color: colors.onSurfaceVariant`
  - If today: `color: colors.primary`
  - Display format: 3-letter day abbreviation using `dayDate.toLocaleDateString('en-US', { weekday: 'short' }).toUpperCase()` — produces "MON", "TUE", etc. Note: `labelSm` already has `textTransform: 'uppercase'` so the toUpperCase() is a safety net.
- **Date number container (today only):** View with `width: 36`, `height: 36`, `borderRadius: borderRadius.full`, `backgroundColor: colors.primary`, `alignItems: 'center'`, `justifyContent: 'center'`
  - Date number text inside: `...typography.titleMd`, `color: colors.onPrimary`
- **Date number (non-today):** `Text` with `...typography.titleMd`, `color: colors.onSurfaceVariant`
  - Display: `dayDate.getDate()` (e.g. "23")
- **isToday check:** Compare year, month, date of dayDate with `new Date()` (today)
- **isSelected check:** Compare year, month, date of dayDate with `selectedDate` prop
- Accessibility per day cell: `accessibilityRole="button"`, `accessibilityLabel` with full date string (e.g. "Monday April 7"), `accessibilityState={{ selected: isSelected }}`
- Use `StyleSheet.create` for all static styles
- Import `useRef`, `useEffect`, `useCallback` from React
