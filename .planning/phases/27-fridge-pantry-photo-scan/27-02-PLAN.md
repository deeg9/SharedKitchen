Create `src/components/scan/ScanReviewScreen.tsx` -- a full-screen modal component that displays scanned items for review before saving to pantry.

**Props interface:**
```typescript
interface ScanReviewScreenProps {
  /** Initial items from the first scan */
  initialItems: Array<{ name: string; category?: string; quantity?: string; brand?: string }>;
  /** Called when user saves or dismisses */
  onClose: () => void;
  /** Called after successful save -- parent should switch to On Hand segment */
  onSaved: (count: number) => void;
}
```

**Component structure and behavior:**

1. **State management:**
   - `items: ScannedItem[]` -- mutable list of review items (initialized from `initialItems` mapped to `ScannedItem` with generated IDs)
   - `editingId: string | null` -- which item is currently being edited inline
   - `scanning: boolean` -- true while a "Scan Another" photo is being analyzed
   - `saving: boolean` -- true during bulk save
   - `photoCount: number` -- starts at 1, increments on each "Scan Another"

2. **On mount (useEffect):**
   - Convert `initialItems` to `ScannedItem[]` with IDs like `scan-${Date.now()}-${index}`
   - Call `findDuplicates(convertedItems, pantryStore.items)` to flag duplicates
   - Set items state

3. **FlatList rendering -- each row:**
   - Show item name (bold), quantity, category pill, brand (if present) in grey
   - If `duplicateOfId` is set: yellow background (`#FFF8E1`), show "Already in pantry" label with existing item name
   - Tap row to toggle inline editing (set `editingId`)
   - When `editingId === item.id`: show TextInput for name, TextInput for quantity, category dropdown (reuse CATEGORY_OPTIONS pattern from AddPantryItemSheet: `['Proteins', 'Produce', 'Dairy & Eggs', 'Pantry', 'Other']`)
   - Delete button: Pressable trash icon on the right side of each row (matching OnHandList's delete button pattern). On press, remove item from list.

4. **"Add item" row at bottom of FlatList:**
   - Persistent row with "+" icon and "Add missed item" text
   - Tap to expand inline form: name TextInput, quantity TextInput, category dropdown
   - Submit adds to items array with a new generated ID

5. **Header:**
   - Title: "Review Items" with item count badge (e.g., "12 items")
   - Close button (X) top-left -- calls `onClose()`
   - "Scan Another" button top-right with camera icon

6. **"Scan Another" button behavior (per SCAN-05):**
   - ScanReviewScreen manages its own CameraSheet. Import CameraSheet and useCameraPermission.
   - "Scan Another" button opens CameraSheet within the review screen.
   - On image captured: call `analyzePhoto('scan', uri)`, convert result items to ScannedItem[], run findDuplicates, append to existing items list, increment photoCount.
   - Show VisionLoadingOverlay during analysis.

7. **Footer:**
   - "Save X items" primary button (full width, colors.primary background)
   - Disabled while saving, shows ActivityIndicator
   - On press: call `bulkAddPantryItems(householdId, items.map(i => ({ name: i.name, quantity: i.quantity, category: i.category })))`, on success call `onSaved(addedCount)`

8. **Empty state:**
   - If all items removed, show "No items to add" with a "Scan Again" button

**Styling:**
- Use colors, typography, spacing, borderRadius from theme (same as AddPantryItemSheet and OnHandList)
- Full-screen modal: `position: 'absolute', top: 0, left: 0, right: 0, bottom: 0, backgroundColor: colors.surface, zIndex: 100`
- Use useSafeAreaInsets for top/bottom padding
- Duplicate rows: `backgroundColor: '#FFF8E1'` with yellow-amber tint
- Category pills: small rounded badges with category text
- Delete button: trash icon on right side of each row (same as OnHandList pattern)

**Error handling:**
- Wrap analyzePhoto in try/catch for "Scan Another"
- VisionRateLimitError: show Alert with upgrade message
- Generic error: show Alert "Couldn't analyze that photo"
- Bulk save error: show Alert with error message, don't close screen

3. **Update handleImageCaptured callback (replace the existing one entirely):**
   ```typescript
   const handleImageCaptured = useCallback(async (uri: string) => {
     setCameraSheetOpen(false);
     setVisionLoading(true);
     try {
       const result = await analyzePhoto(uri, 'scan');
       setVisionLoading(false);
       if (result.items && result.items.length > 0) {
         setScanResults(result.items);
       } else {
         Alert.alert('No items found', 'We couldn\'t identify any food items in that photo. Try taking a clearer photo of your fridge or pantry shelves.');
       }
     } catch (err: any) {
       setVisionLoading(false);
       if (err instanceof VisionRateLimitError) {
         Alert.alert('Monthly scan limit reached', `You've used all ${err.limit} free scans this month. Upgrade to Premium for unlimited scans.`);
       } else {
         Alert.alert('Something went wrong', 'We couldn\'t analyze that photo. Please try again with a clearer image.');
       }
     }
   }, []);
   ```

4. **Add handlers for ScanReviewScreen:**
   ```typescript
   const handleScanClose = useCallback(() => {
     setScanResults(null);
   }, []);

   const handleScanSaved = useCallback((count: number) => {
     setScanResults(null);
     setActiveSegment('onhand');
     Alert.alert('Added to Pantry', `Added ${count} items to On Hand`);
   }, []);
   ```

5. **Render ScanReviewScreen when scanResults is non-null:**
   Define a variable alongside cameraComponents:

   ```typescript
   const scanReview = scanResults ? (
     <ScanReviewScreen
       initialItems={scanResults}
       onClose={handleScanClose}
       onSaved={handleScanSaved}
     />
   ) : null;
   ```

   Then render `{scanReview}` alongside `{cameraComponents}` in every return branch. Since ScanReviewScreen is a full-screen absolute-positioned modal, it will overlay the content.
