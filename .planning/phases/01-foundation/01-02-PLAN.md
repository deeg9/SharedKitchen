  <action>
    1. Create `supabase/migrations/00002_create_households.sql`:
       - `CREATE TABLE households` with: `id UUID DEFAULT gen_random_uuid() PRIMARY KEY`, `name TEXT NOT NULL`, `invite_code TEXT UNIQUE DEFAULT substr(md5(random()::text), 1, 8)`, `created_by UUID REFERENCES profiles(id)`, `created_at TIMESTAMPTZ DEFAULT now()`.
       - `CREATE TABLE household_members` with: `id UUID DEFAULT gen_random_uuid() PRIMARY KEY`, `household_id UUID REFERENCES households(id) ON DELETE CASCADE`, `user_id UUID REFERENCES profiles(id) ON DELETE CASCADE`, `role TEXT CHECK (role IN ('admin', 'member')) DEFAULT 'member'`, `joined_at TIMESTAMPTZ DEFAULT now()`, `UNIQUE(household_id, user_id)`.
       - Enable RLS on both tables.
       - RLS policies per research Pattern 4:
         - households SELECT: user is a member via household_members
         - households INSERT: created_by = auth.uid()
         - household_members SELECT: user is a member of the same household
         - household_members INSERT: user can add themselves (for join flow) -- `WITH CHECK (user_id = auth.uid())`
         - household_members DELETE: only admins can remove members
       - IMPORTANT: To avoid recursive RLS on household_members (Pitfall 6 from research), use a `SECURITY DEFINER` function for the "is member" check, or use `auth.uid()` directly without self-referencing household_members in its own policy.

    2. Create `src/stores/householdStore.ts` -- Zustand store:
       - State: `households: Household[]`, `activeHouseholdId: string | null`, `members: HouseholdMember[]`, `loading: boolean`
       - Computed: `activeHousehold` getter (find by activeHouseholdId)
       - Actions:
         - `fetchHouseholds()` -- query household_members joined with households for current user
         - `setActiveHousehold(id)` -- update activeHouseholdId, fetch members for that household
         - `createHousehold(name)` -- insert household, add creator as admin, refresh list, set as active
         - `joinHousehold(inviteCode)` -- lookup by invite_code, insert member, refresh list, set as active
         - `fetchMembers(householdId)` -- query household_members joined with profiles for the household
       - Persist `activeHouseholdId` to AsyncStorage so it survives app restarts
       - Export `useHouseholdStore`

    3. Create `src/hooks/useHousehold.ts` -- convenience hook:
       - Returns `{ activeHousehold, households, members, loading, switchHousehold, createHousehold, joinHousehold }`
       - Wraps `useHouseholdStore` selectors for ergonomic consumption in components

    4. Create `tests/household.test.ts`:
       - "create" test: Mock supabase insert, verify household created and creator added as admin
       - "invite" test: Verify household has an invite_code after creation
       - "join" test: Mock supabase select by invite_code, verify member is added
       - "members" test: Mock supabase select with join, verify profiles with roles returned

    5. Create `tests/stores/householdStore.test.ts`:
       - Test `setActiveHousehold` updates activeHouseholdId
       - Test `fetchHouseholds` calls supabase correctly
       - Test active household persists to AsyncStorage
