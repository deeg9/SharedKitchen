**Add fetchCookingStats to planStore.ts**:

1. Add new interface above PlanState:
```typescript
export interface CookingStats {
  streak: number;
  completionPercent: number;
  mostCookedRecipe: { name: string; imageUrl: string | null; count: number } | null;
}
```

2. Add to PlanState interface: `fetchCookingStats: (householdId: string) => Promise<CookingStats>`

3. Implementation:
   - Query `meal_plans` table for current month: `.select('*, recipes(name, image_url)')` where `household_id = householdId` and `plan_date >= firstOfMonth` and `plan_date <= lastOfMonth`
   - **Streak**: Sort all meal_plans by plan_date descending. Starting from today, count consecutive days that have at least 1 meal planned. Stop at first gap. If today has no meal, streak = 0.
   - **Completion percent**: `uniqueDatesWithMeals / daysElapsedInMonth * 100` rounded. daysElapsedInMonth = min(today.getDate(), daysInMonth).
   - **Most cooked**: Count recipe_id occurrences, find max. Return { name, imageUrl: recipe.image_url, count }.
   - Return the CookingStats object (do NOT store in global state -- return directly).
