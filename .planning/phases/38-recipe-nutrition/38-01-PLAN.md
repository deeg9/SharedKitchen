   - CORS headers constant (copy from analyze-food-photo)
   - Auth via `supabase.auth.getUser()` from Authorization header
   - Admin client with `SUPABASE_SERVICE_ROLE_KEY`
   - Accept JSON body: `{ recipe_id: string, ingredients: Array<{ amount: number, unit: string, name: string }> }`
   - Rate limit: check ai_usage_log for action_type='match_ingredients', limit 20/month free, unlimited premium (check subscriptions table like analyze-food-photo does)
   - Call Gemini 2.5 Flash (`GEMINI_API_KEY` secret, model `gemini-2.5-flash`) with a structured prompt:
     - System: "You are a food nutrition database matcher. Given recipe ingredient names, find the best matching common food name from a standard food database. Return JSON."
     - User prompt includes the ingredient list. For each ingredient, ask Gemini to return: `{ ingredient_name: string, matched_food_name: string, confidence: number (0-1), amount_grams_estimate: number | null }`
     - Use few-shot examples in the prompt:
       - Input: "2 lbs chicken breast" -> `{ matched_food_name: "chicken breast, raw", confidence: 0.95, amount_grams_estimate: 907 }`
       - Input: "1 cup all-purpose flour" -> `{ matched_food_name: "all-purpose flour", confidence: 0.9, amount_grams_estimate: 120 }`
       - Input: "salt and pepper to taste" -> `{ matched_food_name: "salt", confidence: 0.5, amount_grams_estimate: 2 }`
     - Request `application/json` response MIME type from Gemini
   - For each AI match result with confidence >= 0.3:
     - Search food_items table: `SELECT * FROM food_items WHERE name_normalized ILIKE '%' || matched_food_name || '%' LIMIT 3`
     - If no food_items match, try: search food_search_cache or skip (food_id will be null)
     - Pick best match by data_quality score
   - Build response array: `Array<{ ingredient_index: number, ingredient_name: string, food_id: string | null, food_name: string | null, confidence: number, amount_grams: number | null }>`
   - For ingredients with food_id match: look up food_items.nutrition (per 100g), scale by amount_grams using the formula `nutrition_value * (amount_grams / 100)`, and compute per-ingredient nutrition
   - Compute recipe total nutrition by summing all matched ingredient nutrition values
   - Divide by recipe servings (passed in body as `servings: number`) for per-serving nutrition
   - Save to recipes table: `UPDATE recipes SET computed_nutrition = $perServingNutrition, ingredient_matches = $matchResults WHERE id = $recipe_id`
   - Return: `{ matches: Array<match>, total_nutrition: NutritionData, per_serving_nutrition: NutritionData, matched_count: number, total_count: number }`
   - Log usage in ai_usage_log: `{ user_id, action_type: 'match_ingredients', metadata: { recipe_id } }`
   - Error handling: if Gemini fails, return 500 with `{ error: "AI matching failed" }`. If rate limited, return 429.
  </action>
