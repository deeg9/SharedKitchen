       - Return parsed JSON recipe data
       - Handle errors: invalid URL, fetch failure, LLM parse failure
       - Add CORS headers for Supabase client calls

    5. Create `src/lib/ai.ts`:
       - `parseRecipeUrl(url: string): Promise<RecipeInsert>` -- calls `supabase.functions.invoke('parse-recipe-url', { body: { url } })`, validates response shape, returns typed RecipeInsert (without household_id/created_by -- caller adds those)
       - Loading state handling with progress messages
       - Error handling with user-friendly messages

       - Actions: fetchMealPlan(householdId, weekStart), assignRecipe(householdId, date, recipeId, cookId?, notes?), clearDay(householdId, date), setWeekOffset(offset), getRandomSuggestion(householdId) -- queries random recipe
       - Computed: weekDays() via getWeekDays(weekOffset), weekLabel() via getWeekLabel(weekOffset)
