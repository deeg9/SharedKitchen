  <action>
    1. Create migration `00005_create_grocery_items.sql`:
       - `grocery_lists` table: id (UUID PK), household_id (FK households ON DELETE CASCADE), week_start (DATE), created_by (FK profiles), created_at (TIMESTAMPTZ default now()), UNIQUE(household_id, week_start)
       - `grocery_items` table: id (UUID PK), grocery_list_id (FK grocery_lists ON DELETE CASCADE), name (TEXT NOT NULL), quantity (TEXT), estimated_price (DECIMAL(6,2)), section (TEXT CHECK IN ('Proteins', 'Produce', 'Dairy & Eggs', 'Pantry', 'Other')), is_checked (BOOLEAN default false), checked_by (FK profiles), checked_at (TIMESTAMPTZ), is_manual (BOOLEAN default false), source_recipe_id (FK recipes ON DELETE SET NULL), created_at (TIMESTAMPTZ default now())
       - Enable RLS on both tables
       - grocery_lists RLS: is_household_member(household_id, auth.uid())
       - grocery_items RLS: grocery_list_id IN (SELECT id FROM grocery_lists WHERE is_household_member(household_id, auth.uid()))
       - Enable Realtime: `ALTER PUBLICATION supabase_realtime ADD TABLE grocery_items;`

    2. Extend `src/types/database.ts`:
       - Add grocery_lists table types (Row, Insert, Update)

    3. Create `src/lib/grocery-utils.ts`:
       - `aggregateIngredients(recipes: RecipeWithIngredients[]): GroceryItemInsert[]` -- merge by lowercase name + unit key, sum amounts when units match, list separately when different units
       - `inferSection(name: string): string` -- map common ingredient keywords to sections (Proteins, Produce, Dairy & Eggs, Pantry, Other)
       - `computeSummary(items: GroceryItem[]): GrocerySummary` -- calculate totals, checked count, estimated total, progress percentage
       - `groupBySection(items: GroceryItem[]): Record<string, GroceryItem[]>` -- group items by section for UI rendering

    4. Create `src/stores/groceryStore.ts`:
       - State: items (GroceryItem[]), activeListId (string | null), loading, error
       - Actions:

         - `fetchGroceryList(householdId, weekStart)`: get or create list, fetch items
         - `toggleItem(itemId, checked, userId)`: optimistic update is_checked/checked_by/checked_at, revert on error (GROC-04)
         - `addManualItem(listId, name, quantity?, section?)`: insert with is_manual=true (GROC-07)
         - `removeItem(itemId)`: delete from grocery_items
       - Computed:
         - `summary()`: calls computeSummary(items)
         - `groupedItems()`: calls groupBySection, splits into unchecked sections + completed section
       - Use optimistic UI pattern for toggleItem (update local first, sync to Supabase, revert on error)

    5. Create `src/hooks/useGrocerySync.ts`:
       - `useGrocerySync(householdId: string | null, listId: string | null)`: hook that manages Realtime subscription
       - Subscribe to `postgres_changes` on `grocery_items` table filtered by grocery_list_id
       - Handle INSERT: add item to groceryStore state
       - Handle UPDATE: update item in groceryStore state (handles remote check-offs)
       - Handle DELETE: remove item from groceryStore state
       - Cleanup: remove channel on unmount or when householdId/listId changes
       - Return subscription status for UI indicator
