    1. Create migration `supabase/migrations/00015_create_meal_generation_log.sql`:
       - CREATE TABLE meal_generation_log (id uuid PK, user_id uuid REFERENCES auth.users NOT NULL, household_id uuid REFERENCES households NOT NULL, prompt_context jsonb NOT NULL, suggestions jsonb NOT NULL, tokens_used integer, created_at timestamptz DEFAULT now())

    2. Create `supabase/functions/generate-meal/index.ts`:
       - Same Deno.serve pattern as parse-recipe-url (CORS, auth, admin client)
       - Accept body: { household_id: string, dietary_preferences: string[] }
       - Dietary preferences come from client (AsyncStorage read on client side, sent in request body)
       - Gather context in parallel with Promise.all:
         a. Recent 30 days of meal_plans with recipe names (select recipe_id, plan_date, recipes(name, category, tags))
         b. All household recipes (id, name, category, tags, estimated_cost, servings)
         c. Active leftovers with portions > 0 (name, portions, use_by_date, status)
         d. Current month expenses sum
         e. Budget settings (monthly_target) via maybeSingle()
       - Build prompt summarizing: dietary prefs, recent meals to avoid, available leftovers (prioritize items expiring soon), remaining budget
       - Call OpenAI gpt-5-mini with structured output schema for 3 suggestions:
         ```
         { suggestions: [{ name, description, estimated_cost, prep_time_minutes, uses_leftovers, leftover_items }] }
         ```
       - Set 25-second timeout on OpenAI call to avoid Edge Function timeout
       - Log to meal_generation_log table
       - Check rate limit: 5/day free, 20/day premium (reuse premium detection pattern from parse-recipe-url)
       - Return suggestions array

    3. Add `generateMealSuggestions` function to `src/lib/ai.ts`:
       ```typescript
       export async function generateMealSuggestions(householdId: string, dietaryPreferences: string[]): Promise<MealSuggestion[]>
       ```
       - Calls supabase.functions.invoke('generate-meal', { body: { household_id: householdId, dietary_preferences: dietaryPreferences } })
       - Returns typed MealSuggestion[] array
       - Add MealSuggestion type: { name: string; description: string; estimated_cost: number | null; prep_time_minutes: number | null; uses_leftovers: boolean; leftover_items: string[] }

    4. Write tests in `tests/lib/meal-generator.test.ts`:
       - Test prompt construction helper functions (extract buildMealPrompt as a testable pure function)
       - Test suggestion parsing from structured response
       - Mock the supabase client
