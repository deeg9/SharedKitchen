## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, timer button internal padding |
| sm | 8px | Compact element spacing, timer control gaps |
| md | 16px | Default element spacing, step card padding |
| lg | 24px | Section padding, cooking mode safe area margins |
| xl | 32px | Layout gaps, step card vertical padding |
| xxl | 48px | Progress bar area height, step number badge size |

Exceptions:
- Touch targets for cooking mode timer controls: 48x48px minimum (gloves/wet hands usability)
- Cooking mode prev/next navigation arrows: 56x56px (same as existing bottomBar button height)
- Cooking mode bottom navigation area: 80px height (accommodates progress + nav controls)

Source: src/theme/spacing.ts (existing scale used as-is, no new tokens needed).

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body / Labels | 14px | 400 | 20px (1.43) | Inter |
| Body (default) | 16px | 400 | 24px (1.5) | Inter |
| Titles / Instructions | 24px | 700 | 32px (1.33) | Plus Jakarta Sans |
| Timer Display | 36px | 700 | 44px (1.22) | Plus Jakarta Sans |

Weights used: 400 (Regular) for all body text and labels; 700 (Bold) for headings, titles, emphasis, and display elements.

### Phase 8 Specific Usage

| Context | Size / Weight | Notes |
|---------|---------------|-------|
| Cooking mode instruction text | 24px / 700 | Large text for reading at arm's length; white on dark |
| Cooking mode step indicator | 14px / 400 | "Step 3 of 8" text |
| Cooking mode timer display | 36px / 700 | Countdown digits "04:32" in tabular-nums rendering |
| Cooking mode timer label | 14px / 400 | Timer context label "Simmer" above the countdown |
| Meal suggestion card title | 24px / 700 | Suggestion recipe name |
| Meal suggestion card detail | 14px / 400 | Description, cost, time estimates |
| Unit toggle label | 14px / 400 | "METRIC" / "IMPERIAL" segmented control |

Note on timer digits: Use `fontVariant: ['tabular-nums']` on Inter for fixed-width digit rendering in countdown displays. Do not introduce a monospace font.

## Interaction Contracts

### Cooking Mode Entry (COOK-01)

1. User taps "Start Cooking" in recipe detail bottom bar
2. Screen pushes to `app/(app)/recipe/cook/[id].tsx` (expo-router push, not modal)
3. Status bar hides (`expo-status-bar` set to hidden)
4. Screen renders dark background (#30312e) with first instruction step centered
5. Back gesture or X button (top-left, 40x40px, inverseOnSurface at 60%) exits cooking mode

### Step Navigation (COOK-02)

1. Horizontal swipe (FlatList pagingEnabled) or tap prev/next arrows at bottom
2. Progress bar at top updates: each step is an equal-width segment; completed = inversePrimary, current = inversePrimary at 60%, remaining = onSurfaceVariant
3. "Step X of Y" label centered below progress bar (14px/400, inverseOnSurface)
4. Haptic feedback (Haptics.selectionAsync) on step change
5. On last step: next arrow disabled; "Done Cooking" label replaces next arrow; tapping Done Cooking exits cooking mode

### Countdown Timers (COOK-03)

1. Timer appears inline within StepCard, below the instruction text
2. Timer shows: circular ring (64px), countdown digits centered (36px/700, tabular-nums), label above ring (14px/400)
3. Initial state: ring empty (onSurfaceVariant), digits show full duration, play button (triangle icon) below
4. Tap play: ring animates clockwise fill (secondaryContainer), digits count down, button becomes pause icon
5. Tap pause: ring freezes, digits freeze, button becomes play icon, ring color dims to secondaryFixedDim
6. Tap reset (separate button, right of play/pause): ring empties, digits reset to full duration
7. Timer hits 0:00: ring fills error color, 3 rapid haptic pulses (notificationAsync Success), ring pulses 3x, then settles
8. Background handling: on AppState 'active', recalculate remaining from wall clock. Schedule local notification at timer start for background alert.
9. Multiple timers: each step has independent timer state. Timers continue running when user navigates to other steps. A small "timer running" indicator (pulsing dot + label) shows at top-right of any step if a timer from another step is active.

### Unit Conversion (COOK-04)

1. Segmented control in cooking mode header (top-right area, next to close button)
2. Toggle persists to AsyncStorage key `unit_preference`
3. Switching units: ingredient amounts in sidebar update immediately; inline measurements in instruction text update via regex replacement with smart rounding
4. Default: imperial (US-centric app)
5. Same toggle appears in recipe detail ingredient section (next to existing scale selector row)

### AI Meal Generator (AI-06)

1. Entry point: FAB or prominent button on Recipes tab (reuse "Surprise Me" pattern from meal plan)
2. Tap opens MealGeneratorSheet (bottom sheet, full height minus 60px)
3. Loading state: 3 skeleton cards with shimmer animation (existing Skeleton component)
4. Context summary at top: 3 small pills showing "6 dietary prefs", "3 leftovers to use", "$42 remaining budget" (surfaceContainerLow background)
5. Results: 3 MealSuggestionCards stacked vertically
6. Each card: recipe name (24px/700), 2-line description (14px/400), row of badges (estimated cost, prep time, "Uses leftovers" if applicable)
7. Card CTA: "Add to Plan" ghost button (outline style, primary color)
8. Bottom of sheet: "Try New Suggestions" text button to request fresh suggestions
9. Error state: shown inline in sheet body

## States & Transitions

### Cooking Mode States

| State | Visual |
|-------|--------|
| Step default | Dark background, centered instruction text (inverseOnSurface), step badge top-left |
| Step with timer (idle) | Instruction text + timer component below; ring empty; play button visible |
| Step with timer (running) | Ring filling clockwise (secondaryContainer); digits counting down |
| Step with timer (paused) | Ring frozen (secondaryFixedDim); digits frozen; play button visible |
| Step with timer (complete) | Ring full (error); "00:00" digits; 3-pulse haptic; ring pulses then settles |
| Remote timer indicator | When viewing a step whose timer is NOT active, but another step's timer IS running: small pulsing orange dot + "Simmer 4:32" label at top-right |
| Ingredient sidebar open | Slides in from left (240px wide); semi-transparent overlay on step content |
| Ingredient sidebar closed | Hidden; small "ingredients" pill at bottom-left to open |

### Meal Generator States

| State | Visual |
|-------|--------|
| Sheet closed | Not visible |
| Loading | 3 skeleton cards with shimmer; context pills at top with real data |
| Results | 3 suggestion cards; "Try New Suggestions" at bottom |
| Error | Inline error message with "Try Again" button |
| Empty (no data) | "What should we cook?" heading + body text + CTA |

## Animation Contracts

| Element | Animation | Duration | Easing |
|---------|-----------|----------|--------|
| Step transition | Horizontal slide (FlatList paging) | 300ms | default FlatList deceleration |
| Timer ring fill | Animated circular progress (react-native-reanimated) | Continuous (1 tick/250ms) | linear |
| Timer complete pulse | Scale 1.0 -> 1.1 -> 1.0, 3 cycles | 200ms per cycle | easeInOut |
| Ingredient sidebar | translateX from -240 to 0 | 250ms | easeOut (Easing.out(Easing.cubic)) |
| Meal generator sheet | Slide up (existing BottomSheet pattern) | 300ms | spring (existing) |
| Suggestion card entrance | Fade in + translateY(20 -> 0), staggered 100ms per card | 300ms | easeOut |
| Progress bar segment fill | Width animation on step change | 200ms | easeInOut |
